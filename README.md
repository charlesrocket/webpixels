[![CI](https://codeberg.org/charlesrocket/webpixels/badges/workflows/test.yml/badge.svg?branch=master)](https://codeberg.org/charlesrocket/webpixels/actions)

A WebAssembly library to process PNGs with [pixelmosh](https://codeberg.org/charlesrocket/pixelmosh).

## Example

The example is located in the `www` directory of the repository and deployed at https://charlesrocket.github.io/webpixels/.

## Contributing

Patches are accepted via [Codeberg](https://codeberg.org/charlesrocket/webpixels/) or e-mail.
